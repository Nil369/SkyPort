# Terminal UI (TUI)

The SkyPort Terminal User Interface provides a real-time dashboard in your terminal.

## Starting TUI

```bash
# Start the TUI
skyport start tui

# Start TUI for specific server
skyport --server production start tui
```

## Features

### Dashboard
- System metrics (CPU, Memory, Disk)
- Running containers
- PM2 processes
- Network status

### Container Management
- View running containers
- Monitor container stats
- View container logs
- Execute commands in containers

### Process Management
- List PM2 processes
- Monitor process stats
- View process logs
- Manage process lifecycle

### Terminal Access
- SSH into servers
- Execute remote commands
- Interactive shell

## Navigation

- `Tab` - Switch sections
- `Enter` - Select item
- `q` - Quit
- `?` - Help
- `/` - Search

## Keyboard Shortcuts

- `↑↓` - Navigate
- `Enter` - Select
- `Esc` - Back/Cancel
- `r` - Refresh
- `l` - Logs
- `s` - Stats
- `c` - Connect/Exec
