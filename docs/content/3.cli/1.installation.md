The **SkyPort CLI** is the operator-facing binary. It is named `skyport` and uses local config plus remote server profiles.

![SkyPort CLI](https://ik.imagekit.io/AkashPortfolioAssets/skyport_assets/skyport_cli.png?updatedAt=1778849205758)

## Verify The Binary

```bash [terminal]
skyport --version
skyport help
```

## Local State

The CLI stores its local data under `~/.skyport/`.

```bash
~/.skyport/
├── config.yaml
├── data/
├── workspace/
├── logs/
├── cache/
└── tmp/
```

## Connect To A Server

```bash [terminal]
skyport server add --name local --url http://localhost:8080
skyport server list
```

If you are using multiple environments, select the profile explicitly:

```bash [terminal]
skyport --server local status
```

## Authenticate

```bash [terminal]
skyport login
skyport whoami
```

The CLI stores the returned access token locally for the selected profile.

## Output Modes

The root command supports a simple output switch:

```bash [terminal]
skyport --output json docker ps
skyport --output table pm2 list
```

## Global Flags

- `--config` sets the config file path.
- `--server` chooses a server profile or id.
- `--output` switches between `table` and `json`.

## Shell Completion

```bash [terminal]
skyport completion bash
skyport completion zsh
skyport completion powershell
```

## PATH Verification

### Linux and macOS

```bash [terminal]
which skyport
echo $PATH
```

### Windows

Make sure the folder containing `skyport.exe` is in `Path`, then restart the terminal.

## CLI Automation Examples

### Inspect a server

```bash [terminal]
skyport status
skyport whoami
```

### Inspect resources

```bash [terminal]
skyport docker ps
skyport pm2 list
skyport server ssh
```

### Project and deployment flow

```bash [terminal]
skyport project list
skyport project pull https://github.com/example/app.git --name app
skyport deploy --project-path ./app --start-cmd "npm run start"
```

## Troubleshooting

### `skyport` not found

```bash [terminal]
which skyport
```

### No active server profile

```bash [terminal]
skyport server list
skyport server add --name local --url http://localhost:8080
```

### Auth token missing or invalid

```bash [terminal]
skyport login
skyport logout
skyport login
```
