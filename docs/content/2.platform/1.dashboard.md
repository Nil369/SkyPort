# Dashboard Overview

The SkyPort dashboard is your central control center for managing all infrastructure.

## Dashboard Layout

The dashboard is organized into key sections:

### Navigation Sidebar
- Projects
- Services
- Marketplace
- Monitoring
- Settings

### Main Content Area
- Overview metrics
- Quick actions
- Recent activity
- Status indicators

## Key Sections

### Projects
Manage your deployed applications and services.

```bash
# View projects via CLI
skyport project list

# Create new project
skyport project create my-app
```

### Services
View all running services (Docker containers, PM2 processes, etc.).

### Monitoring
Real-time system metrics and resource usage.

### Marketplace
Browse and install pre-built applications.

## Real-Time Updates

The dashboard uses WebSocket connections for real-time data:
- Container status changes
- Process restarts
- Resource metrics
- Log streams

## Keyboard Shortcuts

- `/` - Search
- `?` - Help
- `p` - Projects
- `s` - Services
- `m` - Monitoring
