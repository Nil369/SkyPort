# VPS Management

Connect and manage remote VPS servers directly from SkyPort.

## Adding a VPS Server

### SSH Connection

```bash
# Add SSH server
skyport vps add-server \
  --name "production" \
  --host "example.com" \
  --user "ubuntu" \
  --port 22 \
  --key /path/to/id_rsa
```

### Password Authentication

```bash
# Add with password (prompted)
skyport vps add-server \
  --name "staging" \
  --host "staging.example.com" \
  --user "ubuntu" \
  --port 22 \
  --auth-type password
```

## Server Operations

### List Servers

```bash
skyport vps list
skyport vps list --format json
```

### Server Information

```bash
# View server details
skyport vps info server-name

# View disk usage
skyport vps disk server-name

# View processes
skyport vps ps server-name
```

### Remote Access

```bash
# SSH into server
skyport vps ssh server-name

# Execute command
skyport vps exec server-name "ls -la"

# Copy files
skyport vps scp server-name:/remote/path /local/path
```

## Firewall Management

```bash
# List firewall rules
skyport vps firewall list server-name

# Add rule
skyport vps firewall add server-name --port 3000 --protocol tcp

# Remove rule
skyport vps firewall remove server-name --rule-id 123
```

## Monitoring

```bash
# Real-time monitoring
skyport vps monitor server-name

# Resource metrics
skyport vps metrics server-name
```
