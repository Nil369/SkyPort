SkyPort ships as a **Go CLI** named `skyport`, plus a **separate backend server binary built** from `backend/`.

## Minimum System Requirements

SkyPort works on lightweight systems, but the recommended minimums are:

- 1 vCPU core
- 512 MB RAM
- 2 GB RAM or more for Docker-based setups

If you are building from the repository root, the supported build targets are:

```bash [terminal]
# Make sure you have make installed on your system!
make backend-build
make cli-build
```

## :icon{name="i-simple-icons-linux" class="text-[#f97316] h-6 w-8"} Linux

Use the release binary or build from source.

::code-group

```bash [release  x86_64.bash]
curl -L -o skyport https://github.com/Nil369/SkyPort/releases/latest/download/skyport-linux-amd64

chmod +x skyport
sudo mv skyport /usr/local/bin/skyport

skyport --version
```

```bash [release  arm64.bash]
curl -L -o skyport https://github.com/Nil369/SkyPort/releases/latest/download/skyport-linux-arm64

chmod +x skyport
sudo mv skyport /usr/local/bin/skyport

skyport --version
```

```bash [source.bash]
git clone https://github.com/Nil369/SkyPort.git
cd SkyPort

# Make sure you have make installed on your system!
make cli-build
make backend-build

sudo install -m 0755 bin/cli/linux-amd64/skyport /usr/local/bin/skyport
sudo install -m 0755 bin/server/linux-amd64/skyport-server /usr/local/bin/skyport-server
```

::

### Linux notes

::warning
- `skyport` must be on your `PATH`.
- `skyport start webui` expects a backend binary such as `skyport-server` or `skyport-backend` on `PATH`, or a custom path passed with `--binary`.
- If you hit permission errors, verify the binary mode and Docker socket permissions.

```bash [terminal]
which skyport
ls -la /usr/local/bin/skyport
```
::

## :icon{name="i-simple-icons-windows11" class="text-[#2563eb] h-6 w-8"} Windows

To Install the **CLI binary** and the **Backend Server binary**, then add its folder to `PATH`.

::note
Open `Powershell` / `GitBash` as ***Admin***
::

::code-collapse
:::code-group

```bash [script.ps1 (Admin)]

Write-Host ""
Write-Host "========================================="
Write-Host "      Installing SkyPort for Windows"
Write-Host "========================================="
Write-Host ""

# Create installation directory
$installDir = "C:\Program Files\SkyPort"

if (!(Test-Path $installDir)) {
    New-Item -ItemType Directory -Path $installDir -Force | Out-Null
}

# -----------------------------
# Download CLI
# -----------------------------

$cliUrl = "https://github.com/Nil369/SkyPort/releases/latest/download/skyport-windows-amd64.exe"
$cliOutput = "$env:TEMP\skyport.exe"

Write-Host "Downloading SkyPort CLI..."
Invoke-WebRequest -Uri $cliUrl -OutFile $cliOutput

Move-Item -Path $cliOutput -Destination "$installDir\skyport.exe" -Force

# -----------------------------
# Download Backend Server
# -----------------------------

$serverUrl = "https://github.com/Nil369/SkyPort/releases/latest/download/skyport-server-windows-amd64.exe"
$serverOutput = "$env:TEMP\skyport-server.exe"

Write-Host "Downloading SkyPort Server..."
Invoke-WebRequest -Uri $serverUrl -OutFile $serverOutput

Move-Item -Path $serverOutput -Destination "$installDir\skyport-server.exe" -Force

# -----------------------------
# Add to PATH
# -----------------------------

$currentPath = [Environment]::GetEnvironmentVariable("Path", "User")

if ($currentPath -notlike "*$installDir*") {
    [Environment]::SetEnvironmentVariable(
        "Path",
        "$currentPath;$installDir",
        "User"
    )
}

# Refresh PATH for current session
$env:Path += ";$installDir"

# -----------------------------
# Verify Installation
# -----------------------------

Write-Host ""
Write-Host "Installed files:"
Get-ChildItem $installDir

Write-Host ""
Write-Host "SkyPort CLI Version:"
& "$installDir\skyport.exe" --version

# -----------------------------
# Start Backend Server
# -----------------------------

Write-Host ""
Write-Host "Starting SkyPort backend server..."

Start-Process `
    -FilePath "$installDir\skyport-server.exe" `
    -WindowStyle Hidden

Start-Sleep -Seconds 3

Write-Host ""
Write-Host "========================================="
Write-Host " SkyPort installed successfully!"
Write-Host "========================================="
Write-Host ""
Write-Host "CLI Command:"
Write-Host "  skyport"
Write-Host ""
Write-Host "Start Web UI:"
Write-Host "  skyport start webui"
Write-Host ""
Write-Host "Backend server started automatically."
Write-Host ""
Write-Host "IMPORTANT:"
Write-Host "Restart PowerShell/CMD if 'skyport' command is not recognized immediately."
Write-Host ""


```

```bash [GitBash.bash (Admin)]
#!/usr/bin/env bash

set -e

echo ""
echo "========================================="
echo "      Installing SkyPort for Windows"
echo "========================================="
echo ""

INSTALL_DIR="/c/Program Files/SkyPort"
TEMP_DIR="/tmp/skyport-install"

mkdir -p "$TEMP_DIR"
mkdir -p "$INSTALL_DIR"

# -----------------------------
# Download CLI
# -----------------------------

CLI_URL="https://github.com/Nil369/SkyPort/releases/latest/download/skyport-windows-amd64.exe"

echo "Downloading SkyPort CLI..."
curl -L "$CLI_URL" -o "$TEMP_DIR/skyport.exe"

mv -f "$TEMP_DIR/skyport.exe" "$INSTALL_DIR/skyport.exe"

# -----------------------------
# Download Backend Server
# -----------------------------

SERVER_URL="https://github.com/Nil369/SkyPort/releases/latest/download/skyport-server-windows-amd64.exe"

echo "Downloading SkyPort Server..."
curl -L "$SERVER_URL" -o "$TEMP_DIR/skyport-server.exe"

mv -f "$TEMP_DIR/skyport-server.exe" "$INSTALL_DIR/skyport-server.exe"

# -----------------------------
# Add to PATH
# -----------------------------

if ! grep -q 'SkyPort' ~/.bashrc; then
  echo '' >> ~/.bashrc
  echo 'export PATH="/c/Program Files/SkyPort:$PATH"' >> ~/.bashrc
fi

export PATH="/c/Program Files/SkyPort:$PATH"

# -----------------------------
# Verify Installation
# -----------------------------

echo ""
echo "Installed files:"
ls -la "$INSTALL_DIR"

echo ""
echo "SkyPort CLI Version:"
"/c/Program Files/SkyPort/skyport.exe" --version

# -----------------------------
# Start Backend Server
# -----------------------------

echo ""
echo "Starting SkyPort backend server..."

cmd.exe /c start "" "C:\Program Files\SkyPort\skyport-server.exe"

sleep 3

echo ""
echo "========================================="
echo " SkyPort installed successfully!"
echo "========================================="
echo ""
echo "CLI Command:"
echo "  skyport"
echo ""
echo "Start Web UI:"
echo "  skyport start webui"
echo ""
echo "Backend server started automatically."
echo ""
echo "IMPORTANT:"
echo "Run the following command if 'skyport' is not recognized immediately:"
echo ""
echo "  source ~/.bashrc"
echo ""

```

## Windows PATH Setup - Manual Method

After installing SkyPort, the `skyport` command should work globally from PowerShell or Command Prompt.

If the command is not recognized, manually add SkyPort to your Windows `PATH`. Expand the Show Properties to see the Step!

::collapsible{label="Show Steps"}
### Steps
:::callout
::steps{level="4"}
#### Open **Start Menu** → search for **Environment Variables**
#### Open **Edit the system environment variables**
#### Click **Environment Variables**
#### Under **User variables** or **System variables**, select `Path`
#### Click **Edit**
#### Add:

```bash [powershell.ps1]
C:\Program Files\SkyPort
```

#### Click **OK** and restart your terminal.

#### Verify Installation:
```bash [powershell.ps1]
skyport --version
```
If installed correctly, SkyPort will print the current version.
::
:::

## Managing the SkyPort Backend Server

During **installation**, **SkyPort  automatically start the backend server** in the **background**.

::steps{level="4"}
#### Stop the Server

::code-group

```bash [skyport_cli.ps1]
skyport stop # Using the latest Skyport CLI
```

```bash [powershell.ps1]
taskkill /IM skyport-server.exe /F
```
::

#### Start the Server Again

::code-group

```bash [skyport_cli.ps1]
skyport start server # Using the latest Skyport CLI
# Or
skyport start
```

```bash [powershell.ps1]
Start-Process "C:\Program Files\SkyPort\skyport-server.exe"
# This command may open a new powershell tab. Don't Panic, Its Ok!
# You can always Stop the server by Pressing "CTRL + C"
```
::

#### Check if the Server is Running
::code-group

```bash [skyport_cli.ps1]
skyport status # Using the latest Skyport CLI
```

```bash [powershell.ps1]
Get-Process skyport-server
```
::
::
> The backend server powers the SkyPort Web UI, API, Docker management, PM2 integration, monitoring system, and other infrastructure services.

## :icon{name="i-simple-icons-linux" class="text-[#0078D4] h-6 w-8"} WSL

WSL behaves like Linux, but Docker access depends on your Windows-side Docker setup.

```bash [terminal]
wget https://github.com/Nil369/SkyPort/releases/latest/download/skyport-linux-amd64
chmod +x skyport-linux-amd64
sudo mv skyport-linux-amd64 /usr/local/bin/skyport
skyport --version
```

### WSL networking notes

- `skyport start webui` will usually bind to `0.0.0.0` on Linux and show the detected LAN IP.
- If you are running Docker Desktop on Windows, make sure WSL integration is enabled.
- If you access the UI from the Windows host, use the address printed by `skyport start webui`.

## Troubleshooting

::steps
### Command not found

```bash [terminal]
which skyport
echo $PATH
```

### Permission denied

```bash [terminal]
chmod +x /usr/local/bin/skyport
ls -la /usr/local/bin/skyport
```

### Docker socket access

```bash [terminal]
ls -la /var/run/docker.sock
sudo usermod -aG docker $USER
newgrp docker
```

### Build from source fails

Use the repository root targets rather than building only a partial package:

```bash [terminal]
make frontend-build
make backend-build
make cli-build
```
