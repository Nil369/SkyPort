This walkthrough uses the real CLI flow: add a project, create a deployment, verify the dashboard, and open logs.

## Step 1. Register a server profile

```bash [terminal]
skyport server add --name production --url https://skyport.example.com
skyport server list
```

## Step 2. Authenticate

```bash [terminal]
skyport login
skyport whoami
```

## Step 3. Pull or register a project

```bash [terminal]
skyport project pull https://github.com/example/my-app.git --name my-app
skyport project list
```

## Step 4. Create a deployment record

```bash [terminal]
skyport deploy \
  --project-path ./my-app \
  --start-cmd "npm run start" \
  --build-cmd "npm run build" \
  --working-directory . \
  --env PORT=3000 \
  --env NODE_ENV=production
```

## Step 5. Read the deployment logs

```bash [terminal]
skyport logs <deployment-id>
```

## Step 6. Roll out or restart

```bash [terminal]
skyport rollback <deployment-id> --mode restart
```

## Production notes

- Keep environment variables out of the command line when they contain secrets.
- Validate port mappings before exposing a service through Caddy.
- Use the dashboard or TUI when you want a quick visual check of health and logs.
