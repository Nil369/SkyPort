## Global Flags

```bash [terminal]
skyport --config ~/.skyport/config.yaml
skyport --server production
skyport --output json
```

## Command Groups

- `auth`
- `server`
- `deploy`
- `rollback`
- `logs`
- `status`
- `docker`
- `files`
- `marketplace`
- `project`
- `pm2`
- `start`
- `service`

## Useful Subcommands

```bash [terminal]
skyport login
skyport server add --name local --url http://localhost:8080
skyport start webui
skyport start tui
skyport pm2 list
skyport docker ps
```

## Output

- `table` is the default.
- `json` is useful for automation.

## Notes

- Do not document `yaml` output unless it is implemented.
- Keep commands grounded in the cobra tree in `cli/cmd`.
