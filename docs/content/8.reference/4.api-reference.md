SkyPort exposes a REST API plus WebSocket streams for real-time workflows.

## Top-Level Endpoints

- `GET /api`
- `GET /api/v1/health`
- `GET /docs/index.html`

## Module Areas

- authentication
- metrics
- VPS
- terminal sessions
- Docker
- PM2
- marketplace
- proxy generation and mappings

## Realistic Doc Writing

When you document an endpoint, include:

1. the purpose
2. the auth requirement
3. the expected response shape
4. whether it is HTTP or WebSocket

## Example

```bash [terminal]
curl http://localhost:8080/api/v1/health
```
